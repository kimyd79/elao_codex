# Phase 0 검증계획

- 모든 제품 라우트가 이전·제외·보류 중 하나로 분류되었는지 확인한다.
- 각 화면의 API 호출과 Vuex/EventBus 의존성이 누락 없이 매핑되었는지 확인한다.
- fixture 재실행 시 동일한 Vue 결과와 수치가 재현되는지 확인한다.
- 로그인/권한/업로드/팝업/다운로드 기준 흐름을 수동 캡처와 체크리스트로 검증한다.
- 첫 화면, 탭 전환, 표 스크롤, 차트 확대·축소의 기준 수치를 기록한다.
- 민감 필드가 화면·로그·다운로드에 노출되는 위치와 마스킹 여부를 확인한다.
- API 계약마다 백엔드 담당, 버전, 호환 유지 기간, 테스트 책임을 지정한다.
- 라이선스·기술 선택 결정마다 대안, 비용, 롤백 방법, 승인자를 기록한다.

완료 조건: 산출물 5종이 존재하고, 미확인 항목에 담당 Phase와 해결 방법이 지정되어 있다.

현재 판정: 완료. 구조·라우트·API·fixture·root smoke·DB 의존 endpoint smoke·3회 HTTP 기준 측정을 완료했다. 분석/차트 POST의 대용량 수치 성능은 Phase 4에서 동일 fixture로 재검증한다.
