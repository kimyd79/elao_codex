# Phase 0 작업방법

- 정적 조사: `rg`로 라우트·axios·store dispatch·EventBus·Lego 사용을 추출한다.
- 동적 조사: 현재 Vue 앱과 Django API를 실행하고 브라우저 개발자 도구 Network 기록을 저장한다.
- fixture: 대표 로그와 요청 JSON을 고정하고 날짜·시간대·집계 해상도를 명시한다.
- 성능: 동일 브라우저와 데이터셋에서 3회 측정 후 중앙값과 p95를 기록한다.
- 조사 중 발견한 API 변경은 구현하지 말고 계약 목록에 먼저 등록한다.
- fixture에는 정상·빈 결과·권한 거부·부분 실패·시간대 경계 사례를 포함한다.
- Network 기록에는 토큰·쿠키·개인정보를 저장하지 않고 즉시 마스킹한다.
- 조사 결과는 각 다음 Phase의 입력 문서와 완료 조건으로 연결한다.
