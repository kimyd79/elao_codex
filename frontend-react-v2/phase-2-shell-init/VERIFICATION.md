# Phase 2 검증계획

- 로그인, 로그아웃, 중복 로그인, 관리자 권한, 세션 만료를 검증한다.
- Init의 각 단계에서 새로고침·이전·다음·취소·재시도 동작을 검증한다.
- Vue fixture와 프로젝트·서버·로그 포맷 저장 결과를 비교한다.
- URL 직접 진입과 브라우저 뒤로가기/앞으로가기를 검증한다.
- 장시간 업로드 중 취소와 실패 후 재시도를 검증한다.
- 같은 저장/삭제/업로드 요청을 두 번 보내도 중복 리소스가 생성되지 않는지 검증한다.
- 새로 고침·브라우저 종료 뒤 미완료 작업과 서버 상태가 올바르게 복구되는지 검증한다.

완료 조건: 기존 Init 핵심 시나리오가 동일한 순서·결과로 동작하고 탭 상태가 복원된다.
