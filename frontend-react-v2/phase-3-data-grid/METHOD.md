# Phase 3 작업방법

- 서버는 불변 정렬 키를 포함한 cursor를 발급하고, 클라이언트는 필터 변경 시 cursor를 폐기한다.
- AG Grid는 업무 래퍼로 감싸 데이터 소스와 컬럼 정의를 교체 가능하게 한다.
- 상세 문맥은 행 선택 시에만 요청하고, 이미 조회한 페이지는 캐시한다.
- 다운로드는 화면 행 재사용이 아니라 별도 비동기 작업 API로 처리한다.
- 부하 테스트는 브라우저 한 대와 API/DB 지연을 분리해 측정한다.
- cursor에는 안정 정렬 키와 조회 시점 정책을 포함하고, 서버가 만료 cursor를 명시적으로 거부한다.
- 화면 표시용 값과 다운로드 원본 값을 분리하고 CSV 셀을 안전하게 escape한다.
