# Phase 3 검증계획

- 초기 응답에 전체 Raw Log가 포함되지 않는지 Network로 확인한다.
- 필터·정렬·페이지 이동·재조회·상세 조회 결과를 Vue와 비교한다.
- 첫 렌더링 시간, 10만/100만 행 스크롤, 메모리, API p95를 측정한다.
- 중복 행, 누락 행, 마지막 페이지, 빈 결과, 오류·재시도를 검증한다.
- 컬럼 고정, 키보드 행 이동, 다운로드 권한을 검증한다.
- 데이터 변경 중 다음 페이지에서 중복·누락이 발생하지 않는지 검증한다.
- 민감 필드 마스킹, CSV formula injection, 다운로드 파일명 및 권한을 검증한다.

완료 조건: 커서 조회가 안정적이고 기준선 대비 메모리·스크롤 목표를 충족한다.
