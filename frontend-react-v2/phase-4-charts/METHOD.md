# Phase 4 작업방법

- 차트 컴포넌트는 option 생성과 데이터 조회를 분리한다.
- 서버에서 가능한 집계를 우선하고, 화면 폭에 맞춰 포인트 수를 제한한다.
- timezone과 집계 구간은 API 응답 metadata에 명시한다.
- 오래된 요청은 AbortSignal로 취소하고 최신 요청만 화면에 반영한다.
- Chart.js와 ECharts의 반올림·빈 구간·누락값 규칙을 먼저 통일한다.
- 차트에는 요약 테이블 또는 다운로드 가능한 데이터 보조 수단을 제공한다.
- 캐시 키에는 프로젝트·로그 파일·필터·시간대·집계 버전을 포함한다.
