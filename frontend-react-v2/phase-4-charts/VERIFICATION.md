# Phase 4 검증계획

- 동일 조건의 합계·평균·비율·상위 항목이 Vue와 일치하는지 확인한다.
- 날짜 경계, timezone, HH/HHMM/HHMMSS 구간을 fixture로 검증한다.
- 초기 렌더링, DataZoom, tooltip, 범례, resize, 재조회 시간을 측정한다.
- 데이터 포인트 상한과 브라우저 메모리 사용량을 확인한다.
- 집계 API 오류·빈 결과·부분 응답 상태를 검증한다.
- 색상만으로 구분하지 않는지, 키보드 사용자에게 값과 상태를 제공하는지 검증한다.
- 빠른 조건 변경 시 오래된 응답이 최신 차트를 덮어쓰지 않는지 검증한다.

완료 조건: 수치 동등성과 차트 상호작용 성능 목표를 동시에 충족한다.
