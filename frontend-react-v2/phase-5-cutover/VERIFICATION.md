# Phase 5 검증계획

- 핵심 사용자 여정의 E2E 성공률과 JavaScript 오류율을 확인한다.
- Vue/React의 fixture 결과, 권한, 오류 메시지, 시간대 결과를 비교한다.
- API p95, 표 스크롤, 차트 DataZoom, 초기 로딩을 Phase 0 기준선과 비교한다.
- 배포 후 health check 실패 시 Vue로 되돌아가는지 검증한다.
- 운영 로그, 모니터링, 사용자 피드백을 안정화 기간 동안 확인한다.
- 구버전 API와 React v2의 호환 기간 동안 롤백 후에도 기존 URL·세션·데이터가 유지되는지 확인한다.
- 운영자가 장애를 재현·판단·롤백할 수 있는지 runbook 리허설을 수행한다.

완료 조건: 기능·수치·성능·접근성·배포·롤백 검증이 모두 통과한다.
