# ELAO 계획 문서

ELAO의 기술 현대화와 기능 개선 계획은 이 디렉터리에서 관리한다.

## 문서 목록

1. [통합 실행 로드맵](ELAO_INTEGRATED_IMPROVEMENT_ROADMAP.md)
   - 실제 작업 순서, 상태, 선행조건 및 단계별 승인 기준을 관리하는 최상위 문서
2. [액세스 로그 파싱 및 저장 개선 계획](ACCESS_LOG_PARSING_IMPROVEMENT_PLAN.md)
   - 파싱 정확성, 실패 복구, 압축 처리, 성능 및 저장 구조의 상세 작업
3. [기술 스택 현대화 계획](STACK_MODERNIZATION_PLAN.md)
   - Python, Django, Node, Vue 및 관련 의존성의 현대화 상세 절차

## 관리 원칙

- 작업 진행 상태는 통합 실행 로드맵을 기준으로 갱신한다.
- 세부 구현과 테스트 항목은 연결된 상세 계획을 참고한다.
- 계획 문서를 새로 추가할 때 이 목록에도 링크를 추가한다.
- 완료한 작업에는 관련 커밋 또는 PR과 테스트 결과를 기록한다.
